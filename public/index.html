Crypto Price Alert Bot

Get notified when Bitcoin, Ethereum, Solana, and other cryptocurrencies hit your target price—on Discord and Telegram.

Features

  • Support for 40+ popular crypto symbols
  • Above/below price alerts
  • Checks every 60 seconds
  • Free to use

Install

Add to Discord

Replace YOUR_CLIENT_ID with your Discord Application Client ID.

Telegram

Search for @YourBotUsername on Telegram and start a chat.
